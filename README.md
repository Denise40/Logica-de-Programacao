💻 Projetos de Lógica de Programação
📚 Sobre o projeto
Este repositório reúne atividades práticas desenvolvidas durante a disciplina de Lógica de Programação do curso de Ciência de Dados da UNINTER, com o objetivo de aplicar os conceitos fundamentais da programação por meio da criação de pequenos sistemas interativos.

Os projetos simulam situações do cotidiano, utilizando menus, cálculos e operações de compra, proporcionando o desenvolvimento do raciocínio lógico e da capacidade de resolução de problemas.
